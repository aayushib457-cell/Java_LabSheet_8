# Java Development – Lab Sheet 8
## Generics

A collection of 15 Java programs demonstrating the implementation of Generics, reusable code, and type-safe programming.

### Core Concepts
- Generic Classes and Methods
- Single and Multiple Type Parameters
- Generic Pair and Container
- Generic Arrays and Collections
- ArrayList Operations
- Type Safety
- Constructors and Methods
- Generic Student Management System

### Practical Implementations
| Section | Programs |
|---|---|
| Generic Classes | Q1 – Q6 |
| Generic Methods | Q7 – Q8 |
| Generic Collections | Q9 – Q11 |
| Generic Containers | Q12 – Q14 |
| Mini Project | Q15 |

### Technologies
- Java
- JDK 19 or higher
- VS Code / Eclipse / IntelliJ IDEA

### Learning Objectives
- Understand Java Generics and their applications.
- Develop reusable and type-safe code.
- Work with generic classes, methods, and collections.
- Apply Generics in a practical student management system.
